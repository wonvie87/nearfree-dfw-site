# Security policy

## Supported version

The production version deployed from `main` is supported. Historical commits, local development builds, and third-party copies are not supported releases.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include exploit details in a public discussion.

Use GitHub's [**Report a vulnerability** private security-advisory flow](https://github.com/wonvie87/nearfree-dfw-site/security/advisories/new) for the public deployment repository. Include the affected URL or component, reproduction steps, likely impact, and any suggested mitigation. Do not include real credentials, payment details, precise user location, or other personal data in the report.

NearFree engineering will acknowledge the report, assess exposure and severity, coordinate a fix and verification, and disclose details only when users are protected. Please allow a reasonable remediation window before public disclosure.

For listing accuracy, date, price, eligibility, or cancellation concerns that do not create a security impact, use the [Contact & Corrections](https://wonvie87.github.io/nearfree-dfw-site/contact.html) page instead of the security channel.
